# Nalu Marroquinería ✦

Sistema de gestión y E-commerce especializado en marroquinería de marcas premium (Oreiro Love, Trendy, Unicross, muaA!). Este proyecto integra un ecosistema Full Stack moderno para ofrecer una experiencia de compra fluida y una administración eficiente.

## 🚀 Tecnologías Utilizadas

### Frontend
- **React.js**: Biblioteca principal para la interfaz de usuario.
- **Tailwind CSS v4**: Framework de estilos para un diseño moderno y minimalista.
- **Lucide React**: Set de iconos optimizados.
- **React Router Dom**: Gestión de navegación y rutas protegidas.
- **Context API**: Manejo de estado global para la autenticación de usuarios.

### Backend
- **Node.js & Express**: Entorno de ejecución y framework para la API REST.
- **MySQL**: Base de datos relacional para la gestión de usuarios, productos y pedidos.
- **JWT (JSON Web Tokens)**: Sistema de autenticación segura basado en tokens.
- **Bcrypt.js**: Encriptación de contraseñas para máxima seguridad.
- **Google OAuth 2.0**: Integración de inicio de sesión social.
